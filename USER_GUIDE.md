# 📖 User Guide - How to Use CPCA

Welcome to the **Cross-Media Pop Culture Archive**! This guide explains how to explore and use the archive effectively.

---

## 🏠 Getting Started

### Accessing the Site

Visit: **`https://USERNAME.github.io/video-game-culture/`**

(Replace `USERNAME` with the repository owner's GitHub username)

### What You'll See

- **Homepage** — Featured games and latest additions
- **Navigation** — Menu to browse games by category
- **Search bar** — Find games by title or keyword
- **Dark mode toggle** — Comfortable reading in any lighting

## 🎮 Browsing Games

### Home Page
The home page shows:
- Featured game cards
- Latest contributions
- Project description
- Links to contribute

### Games Directory
Click "Games" or navigate to `/games/` to see:

### Searching
Use the **search bar** (top of page) to:
- Search by game title

## 📖 Reading a Game Card

Each game card contains collapsible sections (click to expand):

### 📌 Synopsis
Quick overview of the game and why it matters culturally.

### 📖 Books, Essays & Novels
- Tie-in novels written based on the game
- Academic analysis and criticism
- Related literature that influenced the game

**Example:**
```
* "Shadow of the Colossus Analysis"
  Discusses how the game draws from Japanese landscape painting
  Link: [example.com/article]
```

### 📽 Video Essays & Documentaries
- YouTube video essays analyzing the game
- Behind-the-scenes documentaries
- Developer interviews compiled into videos

**Look for:**
- Video title and creator
- Platform (usually YouTube)
- Duration and topic summary
- Direct link

### 📰 Historical Interviews & Post-Mortems
- Original interviews with developers, directors, composers
- GDC (Game Developers Conference) talks
- "Post-mortem" analysis from game magazines

**Typically includes:**
- Interview date and subject
- What was discussed
- Publication source
- Link to the full interview

### 🎨 Artistic References & Cross-Media Inspirations

This is the heart of CPCA! Each card maps connections to:

**Visual Arts:** Paintings, sculptures, photography
- Which artists inspired the visual style?
- Example: "This game's atmosphere mirrors Caravaggio's use of light and shadow"

**Architecture:** Building styles, design movements
- How do architectural principles appear in level design?
- Example: "The castle layout echoes M.C. Escher's impossible geometries"

**Literature & Philosophy:** Books, philosophies, literary themes
- Which novels or philosophical ideas underpin the narrative?
- Example: "The protagonist's journey parallels Dante's Inferno"

**Music & Sound:** Genres, composers, musical theory
- What music influenced the soundtrack?
- Example: "Jazz-fusion elements in the score echo Herbie Hancock"

**Cinema & Visual Media:** Films, TV, animation
- Which movies share the game's DNA?
- Example: "The Gothic aesthetic mirrors Tim Burton's visual style"

### 🎮 Remakes, Remasters & Ports

A timeline showing:
- Original release date and platform
- All subsequent versions (remasters, ports, remakes)
- Technical notes about each version
- Where to find each version

**Example:**
```
| 2003 | GBA Original | PlayStation 2 exclusive in Japan
| 2007 | Wii Virtual Console | Emulated version
| 2022 | Anniversary Collection | Remastered with modern filters
```

### 🏆 Cultural Impact & Legacy

Analysis of how the game influenced:
- The gaming industry
- Other artists and designers
- Cultural conversations
- Modern game design trends

## 💾 Saving & Sharing

### Saving for Later
1. **Bookmark** the card in your browser (Ctrl+D)

### Sharing
1. Click the **share button** (if available)
2. Or copy the URL and share:

## ❓ FAQ

**Q: Why are some cards incomplete?**  
A: CPCA is crowdsourced! Incomplete cards are works in progress. You can help complete them!

**Q: How often is the site updated?**  
A: Whenever someone contributes. New cards appear live within minutes of being approved.

**Q: Can I download the entire archive?**  
A: Yes! Clone the GitHub repository:
```bash
git clone https://github.com/USERNAME/video-game-culture.git
```
All Markdown files are in `content/` — you own the copy.

**Q: Is this only about AAA games?**  
A: No! Indie games, experimental titles, and cult classics are welcome.

**Q: Can I use this archive in my research?**  
A: Absolutely! Content is CC BY 4.0 licensed (free reuse with attribution).

**Q: What if a link is broken?**  
A: [File an issue](../../issues) or contribute a fix via [CONTRIBUTING.md](CONTRIBUTING.md).

**Q: Can I use this for commercial purposes?**  
A: Yes, as long as you credit the creators (CC BY 4.0 license).

**Q: How do I cite a card in academic work?**  
A: Example:
```
Cross-Media Pop Culture Archive. "Castlevania: Aria of Sorrow (2003)."
GitHub. Accessed [DATE]. https://[URL]/games/castlevania-aria-of-sorrow
```

**Q: Can I translate cards to other languages?**  
A: Yes! Please contribute the translation via Pull Request (see CONTRIBUTING.md).
